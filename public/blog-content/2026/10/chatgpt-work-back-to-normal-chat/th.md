เมื่อไม่นานมานี้ผมเจอเรื่องค่อนข้างชวนงงกับ ChatGPT ผมเข้าใช้งานตามปกติ แล้วมีคำเชิญให้ลอง **Work** พร้อมปุ่ม **«Try Work»** คุ้นตา ขอบอกไว้ก่อนว่าผมรู้ว่า Work คืออะไรและเคยใช้มาแล้ว ที่กดไปก็เพราะคิดว่า *«ลองดูซิว่าเขาใส่อะไรใหม่ ๆ ไว้ใน Work หรือเปล่า»*

ความคิดตอนนั้นง่ายมาก: *«อ้อ โอเค มันคงพาไป Work ดูว่ามีอะไรใหม่แล้วค่อยกลับมาใช้ ChatGPT แบบเดิม»* เหมือนฟีเจอร์ใหม่อื่น ๆ อีกมากมาย ผมไม่คิดเลยว่าการกดครั้งนั้นจะทำให้เรื่องพื้นฐานอย่างการเริ่มบทสนทนาธรรมดากลายเป็นเรื่องยุ่งยาก

แต่พอจะกลับ ผมกลับเจอเซอร์ไพรส์: **ChatGPT ยังเปิดเป็น Work อยู่ และตัวเลือกสำหรับสลับระหว่าง Chat กับ Work ก็หายไป** พูดอีกอย่างคือ ตัวเลือกที่ผมหวังจะใช้ย้อนการเปลี่ยนแปลงนั้นเหมือนจะอันตรธานไปเสียเอง

ผมไม่ได้ตั้งใจเปิด Work ให้เป็นรูปแบบการใช้ ChatGPT ตามปกติของผม ผมแค่อยากดูว่ามีอะไรใหม่ ผมเลยลองหาวิธีเรียกหน้าตาแบบเดิมกลับมา และรวบรวมทางเลือกเหล่านี้ไว้เผื่อมีคนเจอแบบเดียวกัน

> **หมายเหตุ:** วิธีจากคอมมูนิตี้ที่อยู่ในบทความนี้เป็น *ทางเลี่ยง* ไม่ใช่การแก้ไขอย่างเป็นทางการที่รับประกันผล หน้าตาของ ChatGPT เปลี่ยนบ่อย และบางวิธีใช้ได้เฉพาะบนเว็บหรือเฉพาะในแอปเดสก์ท็อปเท่านั้น

## ChatGPT Work คืออะไร และทำไมหน้าตาถึงต่างออกไป

ChatGPT มีสองประสบการณ์ที่แยกจากกัน: **Chat** สำหรับสนทนา ถามคำถาม และใช้ผู้ช่วยแบบที่คุ้นเคย กับ **Work** ซึ่งมุ่งไปที่งานยาวที่ต้องทำหลายขั้นตอน ส่วน **Codex** เป็นอีกประสบการณ์หนึ่ง เน้นเรื่องการเขียนโปรแกรม

ไม่ใช่ว่า Work ไม่ดี เพียงแต่ผมไม่อยากใช้มันกับทุกเรื่อง ถ้าผมเข้ามาถามอะไรเร็ว ๆ ก็ควรเริ่มแชทธรรมดาได้โดยไม่ต้องต่อสู้กับอินเทอร์เฟซ

ตาม[เอกสารของ OpenAI เรื่อง ChatGPT Work และ Codex](https://help.openai.com/es-419/articles/20001275-chatgpt-work-and-codex) ในแอปเดสก์ท็อปควรจะเลือก **ChatGPT** แล้วเลือกต่อว่า **Chat** หรือ **Work** ได้ ปัญหาจะเริ่มเมื่อตัวเลือกนั้นไม่อยู่ในที่ที่ควรอยู่

## วิธีที่ 1: เปิด Chat ปกติโดยตรงจาก URL (เว็บ)

ทางเลือกที่ง่ายที่สุดที่ผมเจอสำหรับเวอร์ชันเว็บมาจาก[กระทู้ Reddit เรื่องการกลับไปใช้ Chat แทน Work](https://www.reddit.com/r/ChatGPT/comments/1vz0wqs/anyone_able_to_get_it_to_default_to_chat_instead/)

วิธีคือเปิดที่อยู่นี้:

[**https://chatgpt.com/bot**](https://chatgpt.com/bot)

ผู้ใช้รายหนึ่งอธิบายว่าเส้นทางนี้พาเขาเข้าสู่ประสบการณ์ **Chat** แบบปกติได้โดยตรง แม้ก่อนหน้านั้นจะใช้ Work อยู่ เขายังบอกด้วยว่าเมื่อเข้าทางนี้ ตัวเลือก Chat/Work อาจไม่แสดง แต่ในกรณีนั้นเป็นเพราะเส้นทางดังกล่าวบังคับให้แสดงมุมมอง Chat อยู่แล้ว

ถ้าใช้ได้ผล คุณบันทึกเป็นบุ๊กมาร์กไว้ แล้วใช้เปิด ChatGPT แบบเดิมได้

**สำคัญ:** `/bot` เป็นทางเข้าสำรองที่คอมมูนิตี้แชร์กัน ไม่ใช่ตัวเลือกอย่างเป็นทางการที่มีเอกสารรองรับสำหรับรีเซ็ตโหมดเริ่มต้นของบัญชี มันอาจเลิกทำงานหรือมีพฤติกรรมต่างออกไปในเวอร์ชันถัดไป และ **การเข้าผ่าน URL นี้ไม่ได้แปลว่าคุณได้ตัวเลือกกลับคืนมาแล้ว**

## วิธีที่ 2: สลับไป Codex แล้วกลับมา ChatGPT (แอปเดสก์ท็อป)

ถ้าปัญหาเกิดในแอปเดสก์ท็อปของ ChatGPT ยังมีอีกวิธีที่ผู้ใช้ซึ่งสูญเสียตัวเลือก **Chat/Work** รายงานไว้:

1. เปิดเมนูของแอป แล้วสลับจาก **ChatGPT** ไปเป็น **Codex**
2. สร้าง **แชทใหม่** ใน Codex
3. สลับจาก **Codex** กลับไปเป็น **ChatGPT**
4. สร้าง **แชทใหม่** อีกครั้ง
5. ตรวจดูว่าตัวเลือก **Chat / Work** กลับมาหรือไม่ แล้วเลือก **Chat**

ลำดับนี้อธิบายโดยผู้ใช้รายหนึ่งใน [issue #49233 ของรีโพ Codex](https://github.com/openai/codex/issues/49233) ซึ่งระบุว่าเขาเรียกตัวเลือกกลับมาได้บน Windows หลังจากวิธีอื่นไม่ได้ผล

นี่ไม่ได้แปลว่าเป็นการแก้ไขอย่างเป็นทางการหรือจะได้ผลทุกเวอร์ชัน แต่ก็สมเหตุสมผลกว่าการติดตั้งใหม่ทั้งหมดโดยไม่รู้ว่าจะช่วยได้ไหม

## วิธีที่ 3: ออกจากระบบแล้วเข้าใหม่

อีกรายงานหนึ่งคือ [issue #48700](https://github.com/openai/codex/issues/48700) เล่าว่าการ **ออกจากระบบอย่างชัดเจน** ในแอป Windows แล้วเข้าสู่ระบบใหม่ ทำให้โหมด Chat และตัวเลือกกลับคืนมา

ขณะเดียวกันก็มีผู้ใช้ที่ออกจากระบบ รีสตาร์ต หรือติดตั้งใหม่แล้ว **ไม่** ช่วยอะไรเลย ผมจึงมองว่านี่เป็นความพยายามง่าย ๆ ที่ลองได้ ไม่ใช่วิธีที่แน่นอน

ก่อนจะลบคุกกี้หรือข้อมูลในเครื่อง ลองแค่ออกจากระบบแล้วยืนยันตัวตนใหม่ก่อน ถ้าใช้บนเว็บ คุณยังลองดูได้ว่าปัญหาเกิดในเซสชันเบราว์เซอร์อื่นหรือไม่ แม้นั่นจะไม่รับประกันว่าการตั้งค่าบัญชีจะถูกแก้ไข

## แล้วสคริปต์ Tampermonkey ที่ตั้ง Chat เป็นค่าเริ่มต้นล่ะ

ในกระทู้ Reddit เดียวกันมีการแชร์ [userscript ชื่อ «ChatGPT Default to Chat»](https://gist.github.com/gabrielzv1233/811a56ee7f59e44a25e6ea8a65697184) ซึ่งทำมาสำหรับตัวจัดการอย่าง Tampermonkey

การทำงานค่อนข้างตรงไปตรงมา: **มันมองหาปุ่ม Chat บนหน้าเว็บ และถ้าปุ่มนั้นมีอยู่และยังไม่ถูกเลือก ก็จะพยายามคลิกให้อัตโนมัติ** เป็นการทำงานอัตโนมัติบนอินเทอร์เฟซ ไม่ใช่การเปลี่ยนการตั้งค่าภายในของบัญชี

และนี่คือรายละเอียดสำคัญ: **ถ้าในมุมมองนั้นไม่มีตัวเลือกหรือปุ่ม Chat อยู่เลย สคริปต์ก็ไม่มีอะไรให้คลิก** ดังนั้นมันอาจมีประโยชน์กับคนที่ยังเห็นตัวเลือกแต่กลับเข้าสู่ Work ทุกครั้งที่เริ่มใช้งาน ไม่จำเป็นว่าจะช่วยคนที่ตัวเลือกหายไปหมดแล้ว

นอกจากนี้มันยังเป็นโค้ดของบุคคลที่สามที่รันในเบราว์เซอร์ของคุณ ถ้าตัดสินใจจะใช้ ควรตรวจสอบโค้ดและสิทธิ์ที่ขอก่อนติดตั้ง ในเมื่อแค่ลอง URL ก็พอแล้ว ผมคงไม่เลือกวิธีนี้เป็นอันดับแรก

## แปลว่าบัญชีของผมถูกล็อกไว้ที่ Work หรือเปล่า

ไม่จำเป็นเสมอไป การที่อินเทอร์เฟซเปิดเป็น Work หรือการที่ตัวเลือกหายไป **ไม่ได้พิสูจน์** ว่ามีการเปลี่ยนการตั้งค่าถาวรบนเซิร์ฟเวอร์ของ OpenAI อาจเป็นปัญหาของอินเทอร์เฟซ เซสชัน เวอร์ชันของแอป หรือการทยอยปล่อยฟีเจอร์ จากภายนอกเราไม่มีทางรู้สาเหตุที่แน่ชัดของแต่ละบัญชี

ไม่ต้องคิดไปเองว่าแชทเก่าเสียหายหรือสูญหาย OpenAI อธิบายว่าบทสนทนาของ Chat และ Work อาจปรากฏรวมกันใน **รายการล่าสุด** วิธีที่ชัดที่สุดในการตรวจว่ากลับมาทำงานตามปกติแล้วหรือยัง คือ **สร้างแชทใหม่** แล้วดูว่ามันเปิดในโหมดไหน

## ถ้าไม่ได้ผลเลย: แจ้ง OpenAI

ถ้าคุณยังติดอยู่กับ Work สามารถติดต่อฝ่ายสนับสนุนได้ที่ [**https://help.openai.com/**](https://help.openai.com/) โดยใช้ไอคอนแชทที่มุมขวาล่าง

ทางที่ดีคืออธิบายว่าการกระทำใดทำให้เกิดปัญหา เกิดบนอุปกรณ์ไหน และคุณลองอะไรไปแล้วบ้าง เช่น:

```text
I clicked "Try Work" in the onboarding prompt. Since then,
ChatGPT opens in Work by default and the Chat/Work selector
is missing. I expected to be able to switch back to normal Chat.

Please help restore the Chat/Work selector or the normal Chat
experience on my account.

Platform: [web / Windows / macOS]
What I've tried: [list your attempts]
```

อย่าใส่รหัสผ่าน รหัสเข้าใช้งาน หรือข้อมูลอ่อนไหวลงในรายงาน

## สรุป

ทั้งหมดนี้เริ่มจากการที่ผมกด **«Try Work»** เพื่อดูว่ามีอะไรใหม่ใน Work ซึ่งเป็นเครื่องมือที่ผมรู้จักและเคยใช้มาแล้ว ผมคาดหวังแบบที่เป็นปกติ คือเข้าไป ดูว่ามีอะไรใหม่ แล้วกลับไปที่ Chat เมื่อไหร่ก็ได้

สิ่งที่น่าหงุดหงิดไม่ใช่ตัว Work เอง แต่คือการพบว่าไม่มีทางกลับที่ชัดเจนไปยัง **Chat** ซึ่งเป็นสิ่งที่ผมอยากใช้ตั้งแต่แรก

ถ้าคุณเจอแบบเดียวกัน ผมจะเริ่มจาก **`https://chatgpt.com/bot` ถ้าอยู่บนเว็บ** หรือ **สลับไป Codex แล้วกลับมา ChatGPT ถ้าใช้แอปเดสก์ท็อป** เป็นคนละเส้นทางสำหรับคนละสถานการณ์ และทั้งคู่ไม่ควรถูกเข้าใจผิดว่าเป็นการแก้ไขขั้นสุดท้ายจาก OpenAI

หวังว่าตัวเลือกกลับไปใช้ Chat ปกติจะมองเห็นได้เสมอ และเราจะไม่ต้องไปหาเคล็ดลับใน Reddit เพื่อเรื่องพื้นฐานขนาดนี้
