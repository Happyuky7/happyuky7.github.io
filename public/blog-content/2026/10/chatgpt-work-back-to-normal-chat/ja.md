少し前、ChatGPT でかなり間の抜けたことが起きました。いつも通り開いたら **Work** を試すよう誘われ、おなじみの **「Try Work」** ボタンが表示されました。念のため言っておくと、Work が何かは知っていますし、以前から使ったこともあります。クリックしたのは、*「Work に何か新しいものが入ったのかな」* と見てみたかったからです。

考えたことはとても単純でした。*「なるほど、Work に移動するんだな。何が新しくなったか見たら、いつもの ChatGPT に戻ればいい」*。新機能ではよくあることです。あのクリックが、普通の会話を始めるというごく基本的な動作を面倒にするとは思いませんでした。

ところが戻ろうとしたとき、驚くことになりました。**ChatGPT は Work で開き続け、Chat と Work を切り替えるセレクターが表示されなくなっていた**のです。つまり、変更を元に戻すために使うはずだった選択肢そのものが消えてしまったように見えました。

私は Work を普段使いの形式にしたかったわけではありません。何が新しくなったのかを見たかっただけです。そこで、通常のインターフェイスを取り戻す方法を調べ、同じ目に遭った人のために次の方法をまとめました。

> **注意:** ここに挙げるコミュニティ由来の方法は *ワークアラウンド* であり、公式に保証された修正ではありません。ChatGPT のインターフェイスは頻繁に変わり、ウェブ版だけ、あるいはデスクトップアプリだけで有効なものもあります。

## ChatGPT Work とは何か、なぜ見た目が違うのか

ChatGPT には 2 つの体験があります。会話や質問など、いつも通りアシスタントを使うための **Chat** と、複数の手順を要する長めの作業に向けた **Work** です。**Codex** はさらに別の体験で、プログラミングに特化しています。

Work が悪いという話ではありません。ただ、すべてを Work で済ませたくはない、というだけです。ちょっとした質問をしに来たなら、インターフェイスと格闘せずに普通のチャットを始められるのが自然でしょう。

[ChatGPT Work と Codex に関する OpenAI のドキュメント](https://help.openai.com/es-419/articles/20001275-chatgpt-work-and-codex)によれば、デスクトップアプリでは **ChatGPT** を選び、その後 **Chat** か **Work** を選べるはずです。問題は、そのセレクターが本来あるべき場所にないときに始まります。

## 解決策 1: URL から通常の Chat を直接開く（ウェブ）

ウェブ版で見つけた最も簡単な方法は、[Work ではなく Chat に戻る方法についての Reddit スレッド](https://www.reddit.com/r/ChatGPT/comments/1vz0wqs/anyone_able_to_get_it_to_default_to_chat_instead/)から得たものです。

次のアドレスを開くだけです。

[**https://chatgpt.com/bot**](https://chatgpt.com/bot)

あるユーザーは、直前まで Work を使っていても、このルートなら通常の **Chat** 体験に直接入れたと説明しています。その入り方だと Chat/Work セレクターが表示されないこともあるが、それはルート自体が Chat 表示を強制しているためだ、とも述べていました。

うまくいくなら、ブックマークしておき、いつも通り ChatGPT を開くのに使えます。

**重要:** `/bot` はコミュニティで共有されている代替の入口であり、アカウントの既定モードを戻すための公式に文書化された手段ではありません。今後のバージョンで動かなくなったり、挙動が変わったりする可能性があります。また、**この URL から入れたからといって、セレクターが戻ったとは限りません**。

## 解決策 2: Codex を経由して ChatGPT に戻る（デスクトップアプリ）

ChatGPT のデスクトップアプリで問題が起きている場合、**Chat/Work** セレクターを失ったユーザーから報告された別の方法があります。

1. アプリのメニューを開き、**ChatGPT** から **Codex** に切り替える。
2. Codex で**新しいチャット**を作成する。
3. **Codex** から **ChatGPT** に戻す。
4. もう一度**新しいチャット**を作成する。
5. **Chat / Work** セレクターが戻っているか確認し、**Chat** を選ぶ。

この手順は [Codex リポジトリの issue #49233](https://github.com/openai/codex/issues/49233) であるユーザーが説明したもので、他の方法がうまくいかなかった後、Windows でセレクターを復活させられたとのことです。

公式な修正というわけでも、すべてのバージョンで有効という保証があるわけでもありませんが、効くかどうかも分からないまま全部を再インストールするよりは試す価値があります。

## 解決策 3: サインアウトして入り直す

別の報告である [issue #48700](https://github.com/openai/codex/issues/48700) では、Windows アプリで**明示的にサインアウト**してから再度サインインしたところ、Chat モードとそのセレクターが戻ったとされています。

一方で、サインアウトも再起動も再インストールも**効かなかった**ユーザーもいます。ですから、手軽に試せる方法ではあっても、確実な解決策とは考えません。

Cookie やローカルデータを消す前に、まずはサインアウトして認証し直すだけ試してください。ウェブなら、別のブラウザーセッションでも同じ問題が起きるか確認できますが、それでアカウント側の設定が直るとは限りません。

## Chat を既定にする Tampermonkey スクリプトは？

同じ Reddit スレッドでは、Tampermonkey のような拡張向けに書かれた [「ChatGPT Default to Chat」というユーザースクリプト](https://gist.github.com/gabrielzv1233/811a56ee7f59e44a25e6ea8a65697184)も共有されていました。

動作はかなり単純です。**ページ内の Chat ボタンを探し、存在していて選択されていなければ、自動的にクリックしようとする**だけです。アカウント内部の設定を変えるのではなく、インターフェイス上の操作を自動化する仕組みです。

ここが大事な点です。**その画面にセレクターや Chat ボタンが存在しなければ、スクリプトにはクリックするものがありません**。つまり、セレクターは見えているのに起動時に Work に戻ってしまう人には役立ちますが、完全に失ってしまった人に効くとは限りません。

加えて、ブラウザー上で実行されるサードパーティのコードです。使うと決めたなら、インストール前にコードと権限を確認してください。URL を試すだけで済むうちは、私なら最初の手段には選びません。

## これは私のアカウントが Work に固定されたということ？

必ずしもそうではありません。インターフェイスが Work で開くことや、セレクターが消えていることは、OpenAI のサーバー側で恒久的な設定が変わった**証拠にはなりません**。インターフェイス、セッション、アプリのバージョン、機能の配信状況のいずれかの問題かもしれません。外からは、個々のアカウントで何が原因かを知ることはできません。

古いチャットが壊れたり失われたりしたと考える必要もありません。OpenAI は、Chat と Work の会話が **最近の項目** にまとめて表示されることがあると説明しています。通常の動作に戻ったか確かめる最も明確な方法は、**新しいチャットを作成**してどのモードで開くかを見ることです。

## どれも効かないとき: OpenAI に報告する

まだ Work から抜け出せない場合は、[**https://help.openai.com/**](https://help.openai.com/) の右下にあるチャットアイコンからサポートに連絡できます。

どの操作で問題が起きたか、どの端末で起きているか、すでに試したことは何かを説明するのが一番です。例:

```text
I clicked "Try Work" in the onboarding prompt. Since then,
ChatGPT opens in Work by default and the Chat/Work selector
is missing. I expected to be able to switch back to normal Chat.

Please help restore the Chat/Work selector or the normal Chat
experience on my account.

Platform: [web / Windows / macOS]
What I've tried: [list your attempts]
```

報告にパスワードやアクセスコード、機微な情報を書かないでください。

## まとめ

すべては、すでに知っていて使ったこともある Work に何が新しく入ったのかを見ようと、**「Try Work」** を押したことから始まりました。期待していたのはいつも通りのことです。入って、新しい部分を見て、好きなときに Chat に戻る、というものです。

もどかしかったのは Work そのものではなく、最初から使いたかった **Chat** に戻る明確な道が見当たらなかったことです。

同じことが起きたなら、**ウェブなら `https://chatgpt.com/bot`**、**デスクトップアプリなら Codex に切り替えてから ChatGPT に戻る**方法から始めます。状況が違えば道筋も違いますし、どちらも OpenAI による確定的な修正と混同すべきではありません。

通常の Chat に戻る選択肢が常に見えていて、こんな基本的なことのために Reddit で小技を探さずに済むようになってほしいものです。
